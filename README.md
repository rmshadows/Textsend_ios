# Textsend_ios / 网页桥（Web）

这里不是原生 iOS App，而是 **局域网网页桥** 的计划与说明：手机用 Safari 等浏览器扫电脑端二维码，经 Web 与 TextSend 电脑侧互传文字/文件。

详细方案见 [`Plan_README.md`](Plan_README.md)。
